### Project notes

- **Vika** *(in progress — launching July 2026)* — Real-time AI fitness coach for Vietnamese home exercisers. Flutter front-end, native Swift/Kotlin platform channels for MediaPipe Pose Landmarker Lite (33 landmarks, ~30 FPS) and ML Kit Selfie Segmentation. Rules-based interpreter system on top of NASM movement assessment. Supabase backend (auth + RLS, Singapore region). Asset-based Vietnamese voice coaching. Repo: `Vinafit-mobile` (legacy name, product is now Vika).
- **Dog Breed Classifier** — 3-layer neural network from scratch in pure NumPy. 867 images, 9 breeds. Xavier init, L2 regularization, numerically stable softmax.
- **Youth Savings** — MERN stack expense tracker that suggests budget-friendly social activities. TypeScript + React + TailwindCSS frontend, Express backend, MongoDB Atlas.
- **Chartwells Automation** *(work)* — Workflow automation tools for Chartwells employees. Python + Excel processing, customtkinter UIs.

### Other current work

- **Gaze Estimation @ WRL Lab** *(research)* — Transfer learning + CNN predicting 2D gaze direction from eye images. [Lab page](https://uwrl.mech.utah.edu/2021/07/02/past-present-future-neck-exo/)
- **Compass** *(upcoming, Nov 2026 demo)* — Agentic AI academic planner for U of U CS students. Goal → semester → quarter → week → daily task with Canvas LMS + Google Calendar context. Lassonde SDI funded. Build starts summer 2026.
